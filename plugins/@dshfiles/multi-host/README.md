# @dshfiles/multi-host

Manage execution machines and runtimes through DSH's shared Host APIs. The package provides a directory of machines and runtime connectors with a UI and CLI backed by the same API.

This is an owned DSH bundle. Use `pnpm build`, `pnpm test`, and `pnpm typecheck` from this package for focused checks. The [validation receipts](docs/validation.md) record historical runtime evidence; open phases and rollout gates remain in the [active plan](../../../plans/multi-host/README.md).
