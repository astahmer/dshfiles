# @dshfiles/optmem-sqlite

Storage adapter for OptMem using Node's `node:sqlite` and SQLite FTS5 search. Depends on [`@dshfiles/optmem-core`](../optmem-core/README.md); the DSH-facing bundle is [`@dshfiles/optmem`](../optmem/README.md).

Run `pnpm build`, `pnpm test`, and `pnpm typecheck` from this package. `pnpm bench` runs its storage benchmark.
