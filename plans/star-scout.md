Date 2026-11-25. Inventory of one snapshot of the personal star corpus, scoped to dshfiles. It is triage input, not a plan: a row becomes work only when it reaches a plugin README, [`docs/`](../docs/README.md) or the backlog. Per [`plans/README.md`](README.md), delete this file once every row is either adopted, ported, recorded in docs or dropped.

Before any adopt, apply the rules in [`AGENTS.md`](../AGENTS.md) "Verify against the installed runtime, not the README" and [`docs/community-plugin-audit.md`](../docs/community-plugin-audit.md).

## Decisions this changes

1. **`jj-integration`'s "one jj workspace per thread" is now one implementation of a provider, not the design.** `dsh-layerfs` exists and works over shared history; if isolation gets harder to maintain, the fallback is a layered workspace behind the same operation. Probe it in `probe`, never `profiles/web` — it rewrites files under threads.
2. **The market and the hub are two browsers of the same catalog.** `dsh-market` (12,000+ plugins, one-click install, inside DSH) versus `capabilities-hub` + `plugin-guide`. Keeping both means maintaining discovery twice; pick one and keep only what it cannot do.
3. **Community-plugin review needs a version-compat gate, not just a README check.** Three of the newly starred DSH plugins advertise DSH 0.1.x–0.2.0-rc.2 bands (`dsh-our-free-model`, `dsh-purge`, `dsh-openpencil`) while we run 0.2.2-rc.2, and one of them is the 86k-star "free models" plugin people will ask about. Add the band to [`docs/community-plugin-audit.md`](../docs/community-plugin-audit.md) and to the capability review.
4. **We still have no vision path, and our own evidence is the casualty.** Every UI claim ships screenshots that the text-only models we drive cannot read. `modlens` or a provider fallback is a decision, not an open question, before the next verification claim.
5. **Credential values still reach child processes.** `secret-catalog` resolving to a value is the last hole in "store a reference, never a value"; `agent-vault`'s proxy mode and `varlock`'s schema-plus-scan close it. Cheaper than another round of field-level redaction.
6. **`agentsview` may already be behind its upstream.** `kenn-io/agentsview` (6,533, 2026-11-25) claims 50+ agents and token analytics against our two-agent read-only browser; diff before the next feature lands there.
