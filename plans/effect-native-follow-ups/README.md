# Effect-native branch follow-ups

Work deliberately left open when `refactor/effect-native` was readied for merge. The Effect migration itself is
documented in [the Effect guide](../../tooling/dshx/docs/sdk/effect.md) (its "Known follow-ups" section summarizes
items 1–3); the startup request audit lives in [docs/startup-request-audit.md](../../docs/startup-request-audit.md).

Resume here: pick any row; none blocks the others. Done and removed: the dead `optmem-core` engine (deleted), the
workspace-status poll (now uses the tested `threadStatusPollMs`), the busy-read audit (only project-checks opens
SQLite with a zero busy timeout; every other store waits 5 s natively), and the startup HAR re-capture (the
2026-11-04 capture found `editTimes` at 13.9 s, now one `jj evolog` per page, and remote ownership lookups on every
cold thread open, now skipped for listed local threads; its remaining costs are rows 10–12).
