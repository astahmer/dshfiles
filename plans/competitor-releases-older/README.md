# Competitor releases review, older notes: bb 0.0.29 → 0.47, OpenCode 2.0.26 → 2.2.5, t3code nightlies since late August

This plan reviews releases from before the [2026-11 review](../competitor-releases-2026-11/README.md), plus the t3code
nightlies that review only summarized. It ranks the items we still lack. It skips what that review, the
[t3code parity](../t3code-parity.md) plan (A/B/C/D) and [reference feature additions](../reference-feature-additions.md)
(F/I numbers) already track. It also skips work in progress on 2026-11-11: stuck-turn timeout, one retry per thread,
merged child notices, event-driven PR watching, read negative offset and suggestions, shell exit codes, tool-list
diffs, delta live updates, byte-sized timeline cache, background compaction, cache warming, thread artifacts, find in
thread, model-switch markers, idle cache warning, and tool-search cache-safe mode.

Resume here: pick the next row with status `open` from [Ranked gaps](#ranked-gaps), run its "Check first" step against
the current code, then write its own plan or extend the owning plugin's plan.

## Method and evidence

- Sources, read on 2026-11-11, are untrusted vendor text:
  - bb: the [changelog page](https://getbb.app/changelog), 0.0.29 (2026-07-09) to 0.47.0 (2026-10-23). 0.48 and 0.49
    were read only to avoid duplicates.
  - OpenCode: [`CHANGELOG.md` on `dev`](https://github.com/anomalyco/opencode/blob/dev/CHANGELOG.md), v2.0.26
    (2026-10-08) to v2.2.5. The file starts at v2.0.26. GitHub releases jump from v1.19.x to v2.2.0, so v2.0.0–v2.0.25
    have no reachable first-party notes.
  - t3code: release bodies from `api.github.com/repos/pingdotgg/t3code/releases`, pages 1–4 (2026-08-26 to 2026-11-10,
    about 400 releases). Highlights were deduplicated, and `feat`/`perf` PR titles were scanned. Today's 0.1.9 nightlies
    are excluded.
- "We lack it" means a search of `plugins/@dshfiles/*` READMEs and sources and `docs/` found nothing at `jj:main`
  (2026-11-11). That is lexical evidence, not a check against a running DSH. Rows that are probably partly covered say
  so in "Check first".
- Skipped: mobile-app-only items, Windows-only items, items that need a native desktop app, model-catalog bumps, and
  plain bug fixes. Fixes are kept only when they describe an invariant we could break the same way.
