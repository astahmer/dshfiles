# Competitor releases review, 2026-10-07 → 2026-11-04

Backlog: b:11. This plan lists what competing coding-agent products shipped in the four weeks before 2026-11-04 and
ranks the items we lack. It does not repeat gaps that existing plans already track. Those are referenced by ID:
[t3code parity](../t3code-parity.md) (A/B/C/D), [opencode parity](../opencode-parity.md) and
[reference feature additions](../reference-feature-additions.md) (F-numbers). The broader product comparison of
2026-10-28 lives in [docs/research/harness-landscape](../../docs/research/harness-landscape/README.md).

Resume here: pick the next row with status `open` from [Ranked gaps](#ranked-gaps), confirm its "Check first" note
against the current code, then write its own plan or extend the owning plugin's plan.

## Method and evidence

- Sources are first-party release notes, read on 2026-11-04. GitHub release bodies came from `gh api repos/<repo>/releases`
  and the Claude Code `CHANGELOG.md` from the GitHub contents API. Closed products came from their changelog pages
  through `web_fetch`. Web search was unavailable (no Brave key), so products without a reachable first-party changelog
  are missing (Roo Code is archived; the Codex desktop app has no separate public changelog).
- All competitor text is vendor-stated, not independently tested. "Have" claims on our side were checked against
  plugin READMEs and sources in this repository at `jj:main` (`bf405db5`), not in a running DSH.
- Model-catalog bumps, bug fixes, marketing-site changes and platform-specific items (Windows, Android UI, terminal
  escape codes) are left out.
