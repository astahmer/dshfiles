# Windsurf / Cascade (brand transition)

**Snapshot:** 2026-10-28. Do not describe this as an unchanged standalone Windsurf product: official Windsurf URLs redirected to Devin/Cognition documentation and pricing. Detailed consumer-product claims are uncertain.

## What Cascade historically/currently documents better than DSH

- **IDE-native execution loop:** Cascade documentation presents an editor-integrated agent workflow with codebase context/editing, memories/rules, workflows, MCP, hooks, skills, worktrees, web/docs search, modes and Arena. This is a better-integrated coding surface than the general harness features established in DSH's inspected docs.
- **Desktop and task environment productization:** current official docs describe Devin Desktop, Cascade, installers and release notes. Current pricing page is for Devin, not verified as a legacy Windsurf price schedule.
- The precise Cascade runtime/indexing, OS matrix and consumer privacy/retention behavior could not be independently confirmed from the retrieved official page content; mark **unknown**, not presumed equivalent to Devin cloud.

## DSH overlap and differences

DSH has editor/workbench, skills and MCP, per-thread Jujutsu workspaces, SSH remote runtimes, provider/account orchestration and local telemetry. Likely gap is integrated IDE code context/inline editing and a coherent editor-side agent loop. DSH's strongest difference is durable multi-agent/provider/account orchestration, user-controlled plugins and host-level remote threads.

## Improvements worth considering

1. Pursue editor integration or handoff, not a Cascade clone; make selected code, diagnostics, diff and test context portable to a DSH thread.
2. Improve project rules/skills discovery and show which instructions are loaded, from where and with what trust.
3. Keep DSH positioning complementary as orchestration/control plane; avoid competing for IDE scope without demonstrated user need.
4. Recheck product status and docs before any adoption decision: Windsurf-to-Devin transition may invalidate old pricing, feature and security assumptions.

## Pricing / license / security caveats

The current page listed Devin Free $0, Pro $20/mo, Max $200/mo, Teams $80/mo plus $40/full developer seat, Enterprise contact sales. These are Devin plans with Desktop included, not verified Windsurf-specific prices. No public Windsurf source/license or complete current privacy and retention commitments were established from sources reviewed. Avoid extrapolation.
