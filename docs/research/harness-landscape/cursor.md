# Cursor

**Snapshot:** 2026-10-28. Proprietary editor/product. Official page was branded “The X Subscription” during research; prices can change quickly.

## What it does better than DSH

- **Coding-native IDE (verified):** integrated tab completion, code-aware edit/agent workflows, plans, reviews, debugging, JetBrains/Xcode integrations and cloud agents. Users don't need to assemble an editor layer around a harness.
- **Cloud/enterprise productization (verified):** cloud agents, automations and Bugbot; team distribution/marketplace policy, SSO/SCIM/audit and enterprise privacy/data-governance controls.
- **Portable plugin packaging (verified):** plugin bundles can include rules, skills, agents, commands, MCP servers and hooks; includes a first-party marketplace with review/team policy.
- **Privacy posture (vendor-described):** Privacy Mode, no-training statement, enterprise ZDR/provider controls and cloud-agent repository cleanup claims. Verify the exact current terms/plan for any real evaluation.

## DSH overlap and differences

This DSH profile has MCP, agent tools, plugin marketplace, editor, agent configuration, model/account choices, local telemetry, project checks and Jujutsu workflows. Cursor's edge is the coherent code editor and cloud/enterprise surface, not plugins or MCP per se. DSH tracks Cursor identity/quota but does not run Cursor's coding agent inside DSH.

## Improvements worth considering

1. Build an editor bridge (selection/file/diagnostics in, thread/result/diff out) and keep DSH as the multi-agent control plane.
2. Make plugin bundles easier to discover, audit, pin and share; show provenance, permission requests, supported DSH/runtime range and update source.
3. Improve agent review UX around changed files and test evidence, integrating Jujutsu diff/status and Project Checks.
4. Borrow enterprise policy clarity only where the underlying Host can enforce it; don't overclaim compliance/security equivalence.

## Cost caveat

Pricing page listed Free $0, Plus $8, Premium $30, Super $100 and Ultra $200/month; Teams from $30/seat, Enterprise custom (third-party API spend can be extra). Treat as a time-stamped, volatile observation. Proprietary/closed source.
